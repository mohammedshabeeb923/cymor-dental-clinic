# Hero Video Assets Directory

Drop your high-definition dental treatment video here:
- **`hero-dental.mp4`** (H.264 / AAC, recommended 1080p or 720p, ~5-15MB)
- Optional: **`hero-dental.webm`** (VP9 / WebM)

The CYMOR Dental Clinic hero section is already wired to seamlessly detect and autoplay `assets/hero-dental.mp4`.
While no video file is present, the hero automatically displays the cinematic fallback poster at `images/hero-cinematic-dental.jpg`.
