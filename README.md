# CYMOR Super Speciality Dental Clinic 🦷

A modern, mobile-responsive, high-performance web application for **CYMOR Super Speciality Dental Clinic** (Ponnani, Purangu, Naripparambu, Mandalamkunnu - Kerala, India), founded by Dr. Nazeer P. Chittayil (MDS Orthodontics).

## ✨ Key Features
- **Hero Operatory Showcase**: Featuring Dr. Nazeer P. Chittayil with floating trust badges and instant consultation booking.
- **Ambient Particles & Floating Health Crosses (`+`)**: 60 FPS HTML5 canvas particle system matching the clinic's cyan & teal palette.
- **Interactive Before & After Smile Slider**: Touch & mouse drag comparison across 6 clinical treatments (Aligners, Implants, Veneers, RCT, Periodontics, Pediatric Care).
- **Appointment Booking Engine**: Interactive 4-step wizard with local browser persistence, calendar invite (.ics) sync, and printable receipt.
- **24/7 Dental Emergency Triage**: Instant triage wizard with 1-click WhatsApp SOS dispatch.
- **NRI / Gulf Dental Tourism Benchmark**: Cost estimator and pre-consultation workflow for Gulf (UAE, Saudi, Oman, Qatar, Kuwait) travelers.
- **Floating WhatsApp & Quick Call Actions**: One-touch contact with the clinic.
