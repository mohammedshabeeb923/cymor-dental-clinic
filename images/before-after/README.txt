BEFORE & AFTER CLINICAL CASE PHOTOGRAPHS REPOSITORY

To update or add real clinical before & after photos:
1. Save high-resolution, unedited clinical dental photographs in this folder.
2. Standard naming conventions:
   - Orthodontic Brackets: brackets-before.jpg / brackets-after.jpg
   - Smile Alignment / Aligners: ortho-before.jpg / ortho-after.jpg
   - Dental Implants: implant-before.jpg / implant-after.jpg
   - Smile Makeover & Veneers: veneers-before.jpg / veneers-after.jpg
   - Root Canal Therapy: rct-before.jpg / rct-after.jpg
   - Pediatric Dental Care: pediatric-before.jpg / pediatric-after.jpg
3. Recommended aspect ratio: 4:3 or 16:9 landscape.
4. The website automatically lazy-loads all photos and includes graceful error fallbacks (placeholder-case.svg) if an image is missing or loading.
